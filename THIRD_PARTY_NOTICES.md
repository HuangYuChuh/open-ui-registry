# Third-Party Notices

This file records third-party code redistributed by Open UI Registry.

No third-party component has been accepted at project foundation time.

Each accepted component must add an entry containing:

- component name;
- original author or organization;
- upstream repository and source URL;
- upstream version or commit;
- SPDX license identifier;
- link or path to the full license text when required;
- whether the source was modified;
- a concise description of the modifications.

The repository-level MIT license applies only to original project code and to files explicitly offered under MIT. It does not replace third-party licenses.
